# DiscussionBridge for WordPress

Keep writing in WordPress and host the discussion in Discourse. The plugin
can send eligible WordPress articles to the forum, publish selected topics
as WordPress articles, and show discussions on the site.

Use the block or shortcode to place discussions in WordPress. Configure a
Content Connection in Discourse to choose what can publish in each direction.
WordPress requires PHP 8.1 or later for this plugin.

Build the plugin ZIP with [the packaging script](scripts/build-release.ps1),
then upload it in **Plugins → Add Plugin → Upload Plugin**. [WordPress
profile](https://docs.discussionbridge.dev/platform-profiles/) · [Backup and restore](BACKUP_RESTORE.md)
